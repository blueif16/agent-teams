# Recursive Agents Hackathon

[Recursive Agents Hackathon](https://cerebralvalley.ai/e/crusoe-recursive-agents-hackathon), hosted by Cerebral Valley and Crusoe on Saturday, October 17, 2026 in San Francisco.

The event runs on [Crusoe Managed Inference](https://www.crusoe.ai/cloud/managed-inference), which serves open models, behind one OpenAI-compatible endpoint.

## Getting started

Follow the steps below to get started on Crusoe Managed Inference

1. Sign up for an account here: https://console.crusoecloud.com/request-foundry
    > We recommend one teammate creates the Crusoe organization, then invites the rest of the team into it so everyone can generate their own API token under the same org. Sharing a single token across the team also works fine if you'd rather keep it simple — just make sure whoever holds it doesn't leave before the hackathon ends. **You will need to add a valid credit card to get your free credits.**
2. Submit this form to claim your free credits: https://forms.gle/JdEvMGSb4TURH1Tq8
3. Click **Get API Key** on the top nav bar to generate a key.
    - Give it an alias, and set the expiration date to the hackathon end date (October 18, 2026); this caps your blast radius if the key ever leaks, and avoids surprise charges after the event.
    - Click **Create** and save the key somewhere safe — it's only shown once.
4. Send your first chat request using the sample code in the UI, or give the [Crusoe skill file](crusoe-cv-recursive-agents-hackathon-skill.md) to your coding agent and ask it to start building.

_If you run into any issues, contact a Crusoe team-member in-person at the venue or on Discord._

## What the Crusoe skill file does

[`crusoe-cv-recursive-agents-hackathon-skill.md`](crusoe-cv-recursive-agents-hackathon-skill.md) is a reference you give to a coding agent so it answers common questions about Crusoe Managed Inference. Drop it into your agent's context or as a Claude skill and ask your questions normally.

Ask your agent about:
- Quickstart
- Endpoints
- Models
- Metrics
- Troubleshooting
